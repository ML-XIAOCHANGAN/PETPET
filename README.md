# PETPET

PETPET 是一个安卓虚拟宠物社区原型。每位用户只能领养一只固定外观的小猫，通过每天聊天和互动增加好感度；授权后，小猫可以悬浮在其他应用上方。

## 当前功能

- 默认进入 `MY_PET`，底部固定导航顺序为 `MY_PET`、成长、社区；
- 根据参考图使用原生画布绘制黑色简笔画小猫；
- 小猫持续呼吸浮动，点击触发摇摆、放大和爱心动效；
- 每次应用启动随机显示一条小猫问候；
- 本地持久化宠物、好感度和社区内容；
- 使用 DataStore 持久化日夜主题和小猫日记；
- 日夜主题支持平滑色彩过渡；
- 成长页包含“我的”资料和日记新增、浏览功能；
- 每天完成三轮有效聊天获得一次 `5` 点好感度奖励；
- 每天前五次互动各获得 `1` 点好感度；
- 本地规则式小猫回复；
- 可拖动、贴边、点击返回应用和随时关闭的系统悬浮小猫；
- 用户主动开启后，悬浮小猫可在应用启动或手机重启后自动恢复；
- 社区动态发布、喜欢、评论和举报演示入口；
- 小猫、社区、我的三个主页面；
- 按照 `voxel-icon` 技能规则绘制的等距体素按钮。

## 技术基线

- `Kotlin`
- `Jetpack Compose`
- `DataStore Preferences`
- 最低安卓版本：安卓 8.0
- 目标安卓版本：安卓 15
- Java 17
- Gradle 8.9

## 构建

确保 `JAVA_HOME` 指向 Java 17，并且 `local.properties` 中的 `sdk.dir` 指向已安装安卓 35 平台的开发工具包，然后运行：

```powershell
.\gradlew.bat assembleDebug
```

调试包位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

静态检查：

```powershell
.\gradlew.bat lintDebug
```

当前项目路径含中文，安卓插件需要 `android.overridePathCheck=true`。Windows 下直接从中文路径运行 Gradle 单元测试时，测试运行器仍可能找不到已经编译的测试类。可创建指向项目的纯英文目录联接，并从联接路径运行测试；本轮使用 `F:\Agent-Program\PETPET_WORK` 验证了 12 项测试全部通过。该联接不复制、不覆盖源码。

## 权限说明

悬浮小猫需要用户主动授予“显示在其他应用上层”权限。安卓 13 及以上版本还会请求通知权限，用于让前台服务通知显示在通知抽屉；即使拒绝该通知权限，前台服务仍可运行，通知会保留在系统任务管理器中。开启悬浮小猫后会同时启用自启动；点击“关闭并停用自启动”后不再自动恢复。部分厂商系统还需要在系统管家中单独允许 PETPET 自启动。拒绝悬浮权限不会影响应用内聊天、成长和社区功能。

## 当前边界

本版本是可编译的本地原型，还没有接入账号、服务端、真实社区、对象存储、内容审核或对话模型。正式上线前必须完成这些服务，并在真实安卓设备上验证悬浮窗、通知和厂商后台限制。
