# PETPET 视觉资产生成与接入规格

## 一、适用范围

本规格用于后续生成 PETPET 的聊天、互动、返回、关闭、日记和社区入口图标。现有 `docs/references/cat-assets` 为用户提供的原始资料，只读保留；任何新资产都必须使用新文件名，不覆盖参考原图或当前已接入图片。

本轮会话没有暴露可调用的图像生成接口。按照图像生成与体素图标技能的约束，未在用户未授权的情况下改用需要密钥的命令行方案，因此本轮只交付已经校验的生成规格与提示词，不把“提示词完成”冒充为“图片已经生成”。

## 二、统一视觉参数

- 生成模式：`native`。
- 资产类型：静态单帧位图，不制作循环动画。
- 画布：正方形，建议先生成 `1024 × 1024`，评审通过后再导出安卓所需尺寸。
- 背景：严格使用纯色 `#F4F4F4`，不得渐变、透明、纹理化或改变色值。
- 造型：低密度等距体素，由少量大块、完全不透明、表面受光的亚克力积木组成。
- 镜头：统一等距视角、统一俯视角和朝向；同一图标系列不得随意改变镜头。
- 光照：柔和主光从左上方照射，块面明暗清楚，接触阴影轻且短。
- 构图：主体居中，占画布约六成至七成，四周留出安全边距。
- 禁止项：文字、品牌标识、照片质感、细碎小方块、霓虹描边、玻璃透明、金属高反光、复杂背景、景深虚化和过度装饰。

## 三、系列总提示词

```text
为安卓虚拟宠物应用 PETPET 生成一枚静态等距体素图标。使用 native 模式。图标由少量大型、完全不透明、表面受光的亚克力积木构成，低密度、轮廓清楚、干净可爱。镜头保持统一等距视角，柔和主光从左上方照射，只有轻微短接触阴影。主体居中，占画布约 65%，四周留足安全边距。背景必须是精确纯色 #F4F4F4，不得透明、渐变或出现纹理。不要文字，不要水印，不要照片质感，不要大量碎块，不要复杂场景。
```

## 四、单枚图标补充提示词

在系列总提示词末尾追加以下一项：

1. 聊天：`主体为圆润对话气泡，内含三个大体素圆点；主色为暖白和深炭黑，少量珊瑚橙作为重点。`
2. 互动：`主体为一只圆润猫爪轻触小爱心；猫爪为深炭黑，肉垫为暖灰，爱心为珊瑚橙。`
3. 返回：`主体为简洁弯曲返回箭头，箭头末端带一个极小猫耳轮廓；主色为深炭黑和暖白。`
4. 关闭：`主体为圆角叉号，四个端点像柔软猫爪；主色为深炭黑，中心有极少量珊瑚橙。`
5. 日记：`主体为一本合起的圆角小册子，封面有无文字的猫耳压印；主色为暖白、深炭黑和少量珊瑚橙。`
6. 社区：`主体为两个相邻对话气泡和一个小猫耳轮廓，表达温和分享；主色为暖白、深炭黑和少量珊瑚橙。`

## 五、导出与接入

- 生成原稿先保存到新的评审目录，例如 `docs/成果/待评审视觉资产`。
- 评审通过后复制为新文件名，例如 `voxel_chat.png`、`voxel_interact.png`，放入 `app/src/main/res/drawable-nodpi`。
- 不得覆盖 `cat_main.png`、`floating_paw_button.png` 或 `docs/references/cat-assets` 中任何文件。
- 接入前检查背景色、统一视角、边距、缩小到 48dp 后的辨识度、深浅主题对比度和无障碍文字说明。
- 位图只承担装饰和视觉识别；按钮仍必须由原生可点击控件提供焦点、禁用态、按压反馈和内容描述。
