## 〇、2026-08-15 更新：免费模型 + 直连模式 + 设置界面（本轮）

### 0.1 双模式对话架构（核心变更）

```text
用户填了 API Key → 客户端直连模型 API（OpenAI 兼容，手机有网即可，不依赖电脑）
用户未填 Key    → 走本地网关（.env 免费 Key，仅本机/局域网可用）
全部失败        → 本地规则回复（离线兜底）
```

- **为什么改**：真机上 APK 写死的网关地址 `10.0.2.2`（模拟器专用）连不通 → 永远降级本地规则。
  直连模式让用户在设置页填 Key 后**手机直接调模型**，彻底摆脱网关依赖。
- **直连实现**：`ChatGatewayClient.directChat()`（HttpURLConnection 零依赖，OpenAI 兼容格式），
  系统提示词与网关一致（黑猫人设/60字/多喵）；`max_tokens=200`、8s 超时。
- **本地安全底线**：新增 `data/ClientAudit.kt`（与 server/audit.js 同源精简版）：
  高风险词（自杀/自残…）→ 固定安全回应；普通敏感词 → 降级；**模型输出也过一遍**。
- **Provider 表**（客户端 `ChatProvider` + 网关 PROVIDERS 一致）：ChatGPT(gpt-4o-mini) /
  DeepSeek(deepseek-chat) / GLM(glm-4-flash-250414 免费) / Kimi(moonshot-v1-8k)，全 OpenAI 兼容。
- **实测**：停掉网关 + 模拟器修复 DNS 后，设置填入智谱 Key → 发消息 → AI 回复
  "喵！你好呀，很高兴见到你！有什么想聊的吗？"（无 401、无降级）。

## 一、AI 对话接入（按文档 10 落地）

### 1.1 架构

```text
安卓客户端 → PETPET 网关(Node/Express, server/) → 内容审核+限流 → 智谱 GLM 文本模型
                 ↓ 失败 / 超时 / 审核不通过
              返回 { degraded: true } → 客户端回退本地规则回复
```

- 客户端只发送**匿名 userId**（`local-<小猫名>`）+ 最近 6 条会话历史，不保存模型密钥；
- 模型密钥只存在于网关环境变量（`ZHIPU_API_KEY`），`.env` 已被 git 忽略；
- 网关统一执行：输入校验 → 内容审核 → 限流 → 模型转发 → 输出审核 → 降级。

### 1.2 网关实现（`server/`）

| 模块 | 职责 |
|---|---|
| `src/index.js` | Express 服务：`POST /api/chat`、`GET /health` |
| `src/audit.js` | 敏感词黑名单 + 高风险固定安全回应（自伤/暴力/诈骗/医疗等） |
| `src/rateLimiter.js` | 每用户滑动窗口限流（默认 20 次/分钟） |
| `start.bat` | Windows 一键启动 |

配置（环境变量）：`ZHIPU_API_KEY`(必填)、`PORT`(3002)、`MODEL`(glm-4.5-air)、
`RATE_LIMIT_PER_MIN`(20)、`MAX_INPUT_LEN`(200)。

审核策略：
- 高风险关键词（自杀/自残/不想活/去死）→ 直接返回固定安全回应，**不调模型**；
- 普通敏感词 → 降级 `blocked`，不转发模型；
- 模型回复也过一遍输出审核。

### 1.3 客户端集成

- 新增 `ChatGatewayClient.kt`：HttpURLConnection 实现，零网络依赖，8s 超时；
- `sendMessage` 改为异步流程：立即显示用户消息 + "小猫正在想…"气泡 → 请求网关 →
  成功且未降级用模型回复，否则回退 `replyFor()` 本地规则；
- UI 新增 `petTyping` 状态：显示打字动画气泡，黑猫切换好奇表情，发送中防重复提交；
- Manifest 增加 `INTERNET` 权限 + `usesCleartextTraffic`（开发环境 http 明文）。

### 1.4 实测验证

| 场景 | 结果 |
|---|---|
| 正常对话 | 走模型成功："累了吗？小铃铛给你揉揉肩喵~" |
| 高风险(自杀) | 固定安全回应 `reason: safety` |
| 普通敏感(诈骗) | 降级 `reason: blocked` |
| 空消息 | HTTP 400 |
| 限流 | 单测通过（审核优先于限流） |
