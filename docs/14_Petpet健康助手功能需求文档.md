# 14 Petpet 健康助手（毛孩健康管家）功能需求文档（FRD）

> 版本 v1.0 · 2026-08 · 状态：待评审
> 模块名称：**Petpet 健康助手**（早期草案名「毛孩健康管家」，以本名称为准）
> 宿主 App：PETPET（Android，Kotlin + Compose）
> 文档性质：纯功能层面描述，不含代码与数据库设计

## 0. 文档说明与阅读指引

| 约定 | 说明 |
|---|---|
| 优先级 | **P0**=必须有（首版必须交付）；**P1**=重要、可后续迭代；**P2**=远期规划 |
| 差异化标注 | 🐱=仅猫咪；🐶=仅狗狗；🐾=猫狗通用但有差异规则 |
| 四要素 | 每个功能点按「功能描述 / 用户操作流程 / 系统响应规则 / 异常处理」描述 |
| 术语 | RER=静息能量需求；BCS=体况评分（本文档用简化四档替代完整 9 分制） |

**与通用宠物 App 的关键差异**：本模块嵌入 PETPET，用户在宿主 App 已领养一只宠物（猫或狗）。
因此模块**首启自动带入已领养宠物的类型/名字/品种/年龄**，无需重复建档；
宠物类型（猫/狗）由宿主领养数据决定，后续可手动添加更多宠物。

## 一、功能定位

- **模块名称**：Petpet 健康助手
- **模块目标**：帮助宠主为猫咪和狗狗建立个性化健康档案，生成科学的日常养护计划
  （饮食/运动/疫苗/驱虫），持续监测健康指标，异常时及时预警并给出就医建议。
- **适用对象**：家养宠物猫和宠物犬（不含异宠、爬宠、鸟类）
- **健康免责**：所有建议仅供参考，不能替代专业兽医诊断。
  **入口处（模块首页顶部）常驻免责声明横幅**，预警/自查结果底部统一标注：
  「以上信息仅供参考，不能替代兽医诊断，如有疑虑请及时就医」

### 1.1 页面入口与首启流程

| 项 | 内容 |
|---|---|
| 入口 | 成长页（GrowthScreen）「FitCut 减脂助手」卡片下方新增「🐾 Petpet 健康助手」入口卡片 |
| 首启判定 | 无任何健康档案 → 进入「引导建档」流程 |
| 自动带入 | 检测宿主已领养宠物：自动创建其健康档案（类型=领养品种的猫/狗、名字=宠物名、头像=宠物头像、年龄=按领养日期推算），仅需用户补充：出生日期/性别/绝育状态/体重 |
| 确认 | 用户可「直接用我的宠物建档」或「重新填写」 |

## 三、宠物类型差异化规则总表（核心，不可共用同一套规则）

| 维度 | 🐱 猫咪 | 🐶 狗狗 |
|---|---|---|
| 每日热量 | RER = 70×体重kg^0.75；系数：绝育成猫 1.2 / 未绝育 1.4 / 幼猫 2.5 / 活跃 1.6 | RER 同公式；系数：幼犬 2-3 / 成犬 1.6-1.8 / 老年 1.4 / 工作犬 3-5；另按体型分档 |
| 疫苗核心 | 猫三联（猫瘟/杯状/鼻支）+ 狂犬 | 犬四联/六联/八联（按地区选择）+ 狂犬 |
| 疫苗周期 | 首免 8 周龄起 3 针、间隔 3-4 周；狂犬 3 月龄后；之后每年加强 | 首免 6-8 周龄起 3 针、间隔 3-4 周；狂犬 3 月龄后；之后每年加强 |
| 驱虫 | 体内：幼猫每月、成猫每 3 月；体外：每月（夏季） | 体内：幼犬每月、成犬每 3 月；体外：每月（夏季） |
| 运动量 | 每日互动游戏 15-30 分钟、分多次（逗猫棒等） | 按体型散步 30-120 分钟/日 + 奔跑/训练 |
| 体温 | 38.0-39.2℃ | 37.5-39.0℃ |
| 心率 | 120-220 次/分 | 60-140 次/分 |
| 呼吸频率 | 20-30 次/分 | 15-30 次/分 |
| 易发疾病 | 泌尿系统疾病、慢性肾病、牙周病、甲状腺功能亢进 | 皮肤病、耳道感染、关节问题、胃肠敏感 |
| 食物禁忌 | 洋葱/大蒜、巧克力、葡萄/葡萄干、百合（剧毒）、木糖醇 | 洋葱/大蒜、巧克力、葡萄/葡萄干、木糖醇、牛油果 |
| 饮水关注 | **重点关注**（易患泌尿疾病，饮水量低于推荐值即提醒） | 正常关注 |
| 繁殖周期（未绝育雌性） | 发情期记录（行为表现） | 经期记录（出血量） |

> 规则引擎要求：**所有计划生成、指标判断、预警触发必须按宠物类型走不同分支**，
> 任何「猫狗共用」的规则需在文档/代码中显式标注为通用规则。

## 四、功能清单

### 功能 1：宠物健康档案 【P0】

#### 1.1 添加宠物

- **功能描述**：模块首页「添加宠物」按钮，支持添加多只宠物（猫+狗可混合）。
- **用户操作流程**：模块首页 → 点「添加宠物」→ 填写档案表单 → 保存。
- **系统响应规则**：
  - 类型（猫/狗）必选，选择后表单按类型展示差异化字段；
  - 首启时提供「直接用我的宠物建档」快捷入口（见 1.1 首启流程）；
  - 保存后生成健康卡片，并自动生成健康计划（见功能 2）。
- **异常处理**：必填项缺失时按钮置灰并提示；中途退出未保存 → 丢弃草稿（P1：支持草稿暂存）。

#### 1.2 基础信息字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 宠物类型 | ✅ | 猫/狗；决定后续全部差异化规则 |
| 名字 | ✅ | 1-12 字符 |
| 性别 | ✅ | 公/母 |
| 是否绝育 | ✅ | 是/否；影响热量系数与生理周期功能 |
| 出生日期或年龄 | ✅ | 二选一，自动换算；年龄显示为「X 岁 X 月」（<1 岁显示 X 月龄） |
| 品种 | ✅ | 🐱：常见品种下拉 + 田园猫/串串；🐶：常见品种下拉 + 中华田园犬/串串，按体型分类（小型/中型/大型/巨型） |
| 体重 kg | ✅ | 一位小数；作为热量计算与体型评估输入 |
| 毛色 | 选填 | 自由文本 |
| 头像 | 选填 | 拍照或相册上传（调用宿主相机/相册） |

#### 1.3 健康背景（可建档时填写，也可后续补录）

- 已接种疫苗记录 / 已驱虫记录：可后续补录（见功能 4）。
- 既往病史、过敏史、长期用药：选填自由文本。
- 食物过敏/禁忌：多选（洋葱/巧克力/葡萄/木糖醇/百合/牛油果…）+ 自定义添加；
  保存后在「饮食计划」与「饮食记录」页自动提示禁忌。

#### 1.4 档案视图（健康卡片）

- 每只宠物一张卡片，展示：头像、名字、年龄、体重、
  **体型评估**（偏瘦/标准/偏胖/肥胖）、下次疫苗/驱虫倒计时。
- 卡片点击进入该宠物详情（计划/记录/指标）。

#### 1.5 体型评估

- **功能描述**：根据品种 + 体重 + 体长（可选输入）给出四档评估并附建议。
- **系统响应规则**：
  - 有体长时：按「体重/体长」比值查品种体型标准区间；
  - 无体长时：按品种标准体重区间判断（🐱按品种标准体重；🐶按体型档标准体重区间）；
  - 输出四档：偏瘦 / 标准 / 偏胖 / 肥胖，附一句建议文案
    （如「偏胖：建议逐步增加运动，控制零食，咨询兽医调整饮食」）。
- **异常处理**：体重超出品种区间极端值（如小型犬 30kg）→ 提示核对输入。

### 功能 2：个性化健康计划生成 【P0】

> 建档成功即自动生成；计划可在「我的宠物 → 健康计划」查看与手动调整。
> 生成依据：类型、品种、体重、年龄、绝育状态、活动量。

#### 2.1 饮食计划

- **功能描述**：计算每日推荐摄入热量（RER×系数）并给出喂养方案。
- **系统响应规则**：
  - 每日热量 = RER × 系数（系数见差异化总表）；
  - 🐱 喂养模式四选一：纯干粮 / 干粮+湿粮 / 纯湿粮 / 生骨肉，各模式给出日喂食量与热量占比建议；
  - 🐶 按体型分档：小型/中型/大型/巨型犬喂食量参考（g/日）；
  - 每日喂食次数与单次份量：幼宠 3-4 次、成宠 2 次、老年宠 2-3 次（小份量）；
  - 食物禁忌提醒：按宠物类型展示禁忌清单（见差异化总表），并关联 1.3 自定义禁忌。
- **异常处理**：肥胖宠自动下调热量 10-20% 并提示循序渐进；怀孕/哺乳期 → 不生成标准计划，提示咨询兽医。

#### 2.2 运动计划

- **功能描述**：按类型/体型/年龄给出每日运动建议。
- **系统响应规则**：
  - 🐱：每日逗猫棒/互动游戏 15-30 分钟、分 2-3 次；
  - 🐶：按品种+体型给出每日散步时长+次数（小型 30 分钟×2、中型 45-60 分钟×2、
    大型 60-90 分钟×2、巨型 90-120 分钟×2），附奔跑/玩耍/训练时长建议；
  - 幼宠/老年宠/肥胖宠分别给出注意事项（如肥胖宠循序渐进、避免剧烈跳跃）。
- **异常处理**：老年宠（🐱>10 岁 / 🐶>7 岁 / 大型犬>5 岁）自动切换老年配方并缩短单次运动时长。

#### 2.3 疫苗计划

- **功能描述**：按首免/加强免疫生成时间表。
- **系统响应规则**：
  - 🐱：猫三联首免（8 周龄起 3 针、间隔 3-4 周）→ 1 年后加强 → 之后每年一次；狂犬（3 月龄后，之后按当地法规 1-3 年）；
  - 🐶：犬四联/六联/八联首免（6-8 周龄起 3 针、间隔 3-4 周）→ 1 年后加强 → 之后每年一次；狂犬同猫逻辑；
  - 按**宠物当前年龄**推算下一针日期，生成未来时间表；
  - 非核心疫苗（🐱猫白血病、🐶钩端螺旋体等）标注「咨询兽医后选择」，不进默认计划。
- **异常处理**：补录历史接种日期 → 按实际日期计算下次接种；幼宠 <2 月龄 → 提示未离乳注意事项，疫苗计划从适龄开始。

#### 2.4 驱虫计划

- **系统响应规则**：
  - 体内驱虫：幼宠每月一次，成宠每 3 个月一次（可调整间隔）；
  - 体外驱虫：每月一次（夏季/外出频繁建议），冬季可延长至每 2-3 个月；
  - 🐱/🐶 分别推荐常见驱虫药**类别**（如体内：非班太尔类/米尔贝肟类；体外：塞拉菌素类/氟虫腈类），不指定品牌；
  - 生成未来 12 个月驱虫时间表，体内/体外分开标注。
- **异常处理**：用户可手动调整单次日期，调整后后续节点按新周期重排。

#### 2.5 体检计划

- **系统响应规则**：
  - 幼宠：入园体检建议（领养后 1 个月内）；
  - 成宠：每年一次常规体检；
  - 老年宠（🐱>10 岁 / 🐶>7 岁 / 大型犬>5 岁）：每半年一次，增加生化、心脏、甲状腺等专项检查建议。

#### 2.6 健康日历

- **功能描述**：计划生成后展示为「健康日历」。
- **系统响应规则**：未来 30 天内所有待办（疫苗/驱虫/体检/用药/喂食/称重）按日期排列，
  每天可展开查看明细；待办可手动调整日期（调整后提醒随之更新）。
- **异常处理**：跨月视图需明确标注月份分隔；无待办日期显示空态提示。

### 功能 3：日常健康记录 【P0（核心记录）/ P1（部分子项）】

> 所有记录按宠物独立存储；记录入口：宠物详情 → 对应记录卡片，或首页快捷记录。

#### 3.1 饮食记录 【P0】

- **功能描述**：记录每餐食物与份量，对照推荐摄入量。
- **用户操作流程**：选宠物 → 饮食记录 → 「+ 添加」→ 选择食物/自定义 → 填份量与时间 → 保存。
- **系统响应规则**：
  - 记录项：食物名称、份量（g）、喂食时间；
  - 「今日推荐菜单」：按当日推荐热量与计划，预置 2-3 个快捷项（可一键添加）；
  - 自定义食物录入（名称、热量/100g），保存后进入个人食物库；
  - 食欲状态：正常 / 食欲下降 / 拒食（必选其一）；
  - 当日汇总：已摄入 vs 推荐摄入量进度条。
- **异常处理**：⚠️ 若勾选「食欲下降」或「拒食」→ 写入异常信号，供功能 5 预警；食物命中禁忌清单 → 红色提示并二次确认。

#### 3.2 饮水记录 【P0（🐱）/ P1（🐶）】

- **功能描述**：记录饮水量并展示每日进度。
- **用户操作流程**：选择水碗容量估算（如 200ml/碗）→ 记录本次饮水量（ml）。
- **系统响应规则**：
  - 🐱 每日推荐饮水量约 40-60ml/kg（按体重动态计算），低于推荐值 80% 时页面提醒；
  - 展示当日饮水进度条。
- **异常处理**：饮水量骤增或骤减（较 7 日均值 ±50%）→ 触发预警（见功能 5）。

#### 3.3 排泄记录 【P0】

- **功能描述**：记录排便/排尿，异常可标注。
- **用户操作流程**：选择记录类型（排便/排尿）→ 填写对应字段 → 保存。
- **系统响应规则**：
  - 排便：次数、形状（**布里斯托分级 1-7 型可视化选择**，配图示）、颜色、是否有血/黏液、异常标注；
  - 排尿：次数、尿量（多/正常/少）、颜色；
  - 🐱 排泄异常（尿频/尿少/尿血/尿闭）→ **高优先级预警**，建议立即就医；
  - 展示近 7 天频次概览。
- **异常处理**：布里斯托 1 型或 7 型 → 提示关注并写入预警；连续 2 天未排便或腹泻（6-7 型）→ 触发预警。

#### 3.4 运动记录 【P1】

- **功能描述**：记录运动类型、时长、完成状态，展示本周完成率。
- **系统响应规则**：
  - 运动类型：🐱互动游戏 / 🐶散步/奔跑/训练；
  - 🐶 可记录散步路线距离（预留，调用宿主定位能力）；
  - 本周完成率 = 实际完成次数 / 计划次数。
- **异常处理**：长期未完成（连续 3 天 0 记录）→ 首页温和提示。

#### 3.5 体重记录 【P0】

- **功能描述**：记录体重并生成变化曲线。
- **用户操作流程**：宠物详情 → 体重记录 → 输入体重（kg）→ 保存；建议每周固定时间称重（可设置提醒）。
- **系统响应规则**：
  - 同日重复记录 → 覆盖；
  - 自动生成体重变化折线图（1 月/3 月/1 年/全部，标注标准体重区间参考线）；
  - **一周内波动 >5% → 触发提醒**（上升=可能过度进食/疾病，下降=可能疾病）。
- **异常处理**：输入超出 0.5-100kg → 提示核对。

#### 3.6 精神状态记录（选填）【P1】

- **功能描述**：记录活跃度与异常症状。
- **系统响应规则**：
  - 活跃度：活泼 / 正常 / 萎靡；
  - 异常症状多选：呕吐、咳嗽、打喷嚏、挠痒、掉毛异常、眼屎增多、泪痕、跛行、抽搐等；
  - 勾选症状 → 自动关联到「健康预警」列表。
- **异常处理**：勾选「抽搐」「跛行」等严重症状 → 直接红色预警。

---

### 功能 4：健康指标与医疗追踪 【P0（疫苗/驱虫）/ P1（其余）】

#### 4.1 疫苗管理 【P0】

- **功能描述**：疫苗记录与状态管理。
- **用户操作流程**：宠物详情 → 疫苗 → 「+ 接种记录」→ 填名称/日期/机构/下次日期 → 保存；可上传疫苗本照片。
- **系统响应规则**：
  - 已接种标记绿色；待接种显示倒计时（X 天后）；**逾期未接种标红提醒**；
  - 补录历史日期 → 按实际日期计算下次接种。
- **异常处理**：疫苗名称不在内置列表 → 支持自定义输入。

#### 4.2 驱虫管理 【P0】

- **功能描述**：体内/体外驱虫记录与倒计时。
- **用户操作流程**：同疫苗管理（药物名称、日期、下次日期）。
- **系统响应规则**：倒计时提醒；逾期标红。

#### 4.3 体检与就医记录 【P1】

- **功能描述**：体检与就医档案沉淀。
- **用户操作流程**：
  - 体检记录：日期、机构、体检项目、结果摘要、上传报告照片；
  - 就医记录：日期、医院、诊断、用药、医嘱、复诊日期；
  - 用药提醒：根据医嘱设置用药时间与周期（如每天 2 次、连服 7 天）。
- **系统响应规则**：复诊/用药到期进入健康日历与提醒队列。

#### 4.4 生理周期（仅未绝育雌性）【P2】

- **功能描述**：记录繁殖周期并预测下次。
- **用户操作流程**：记录开始/结束日期与表现。
- **系统响应规则**：
  - 🐱：发情期记录（行为表现）；🐶：经期记录（出血量）；
  - 按周期均值（🐱约 14-21 天 / 🐶约 6-8 个月）预测下次时间并提醒。
- **异常处理**：🐶 经期异常延长（>21 天）→ 提示咨询兽医。

### 功能 5：健康预警与异常识别 【P0】

#### 5.1 自动预警（基于记录数据触发）

| 触发条件 | 优先级 | 建议动作 |
|---|---|---|
| 连续 2 天食欲下降或拒食 | 黄 | 建议就医，排查口腔/消化道问题 |
| 连续 2 天未排便或腹泻（布里斯托 6-7 型） | 黄 | 建议就医 |
| 🐱 排尿异常（尿频/尿少/尿血/尿闭） | **红** | **立即就医**（泌尿系统急症） |
| 体重一周内波动 >5% | 黄 | 回顾饮食/就医 |
| 饮水量较 7 日均值骤增/骤减 ±50% | 黄 | 关注（🐱尤需警惕肾脏/糖尿病） |
| 疫苗/驱虫逾期 | 黄 | 尽快补种/补驱 |

- **系统响应规则**：预警生成后进入「最近异常提醒列表」（首页）；红色预警置顶并强提醒。
- **异常处理**：预警在用户标记「已处理」前保持可见；连续触发同类预警去重（同因 3 天内不重复弹）。

#### 5.2 症状自查（用户主动输入）【P0 基础版 / P1 知识库完善】

- **功能描述**：用户选择症状组合，系统给出参考信息。
- **用户操作流程**：宠物详情 → 症状自查 → 多选症状（呕吐/腹泻/咳嗽/打喷嚏/挠痒/掉毛异常/眼屎/泪痕/跛行/抽搐等）→ 提交。
- **系统响应规则**：
  - 输出：可能原因、严重程度评估、家庭护理建议、是否需要就医；
  - 严重程度三级：
    - 🟢 绿色-可观察：家庭护理建议 + 观察时长（如 24-48 小时）；
    - 🟡 黄色-建议就医：列出可能需要做的检查；
    - 🔴 红色-紧急就医：明确提示尽快送医，列出就近医院（预留，调用宿主地图/搜索）；
  - **多选多个严重症状 → 直接红色预警，不展示家庭护理建议**，优先就医。
- **异常处理**：自查结果底部统一标注免责声明；知识库按 🐱/🐶 分流（同症状猫狗严重度不同）。

#### 5.3 免责声明

所有预警与自查结果底部统一标注：
「以上信息仅供参考，不能替代兽医诊断，如有疑虑请及时就医」

### 功能 6：提醒系统 【P1（依赖宿主推送）】

#### 6.1 提醒类型与提前量

| 提醒 | 提前量 |
|---|---|
| 疫苗 | 提前 7 天 + 当天 |
| 驱虫 | 提前 3 天 + 当天 |
| 体检 | 提前 14 天 + 当天 |
| 用药 | 按医嘱频率 |
| 喂食 | 每日自定义时间点 |
| 称重 | 每周一次（自定义星期+时间） |
| 🐱 换水/清洁猫砂 | 可选 |

#### 6.2 提醒方式

- 调用宿主 App 推送能力；支持**总开关 + 每类开关 + 时间自定义**；
- 多宠物时，提醒内容**明确标注宠物名字**（如「🐱 咪咪：明天该打猫三联啦」）；
- 提醒文案进入健康日历并同步展示。

#### 6.3 异常处理

- 推送权限未授权 → 应用内横幅提示替代（降级）；用户关闭某类提醒 → 仅该类静默。

### 功能 7：数据统计与健康报告 【P1】

#### 7.1 健康概览首页

- 每只宠物**今日待办**（喂食/运动/用药/疫苗等，从健康日历汇总）；
- **本周健康评分**（0-100，基于记录完整度 + 异常情况：完整记录加分、异常事件减分、红色预警大幅减分）；
- 最近异常提醒列表。

#### 7.2 体重趋势图 【P0 曲线 / P1 参考线】

- 折线图，支持 1 月/3 月/1 年/全部切换，标注标准体重区间参考线。

#### 7.3 饮食统计 【P1】

- 日均热量摄入、饮水趋势、食欲正常率。

#### 7.4 运动统计 【P1】

- 周/月运动时长、完成率。

#### 7.5 排泄统计 【P1】

- 排便/排尿频次趋势、异常次数统计。

#### 7.6 月度健康报告 【P1】

- 本月体重变化、饮食运动达标率、健康评分变化；
- 疫苗驱虫完成情况；
- 异常事件回顾；
- 下月健康建议；
- **支持分享为图片**（调用宿主分享能力）。

#### 7.7 健康档案导出 【P1】

- 汇总：基础信息 + 疫苗驱虫记录 + 就医记录 → 生成可分享文本/图片，方便就医时给兽医参考。

### 功能 8：多宠物管理 【P0】

#### 8.1-8.3

- 支持添加多只宠物，🐱🐶可混合；
- 首页顶部**宠物切换栏**（头像横向滚动），切换后该宠物的计划/记录/提醒/统计完全独立展示；
- 每只宠物数据严格隔离。

#### 8.4 删除宠物

- 需**二次确认**（明确提示「删除后数据不可恢复」）；删除后同步清除该宠物全部计划/记录/提醒。

#### 8.5 与宿主领养宠物的关系

- 宿主已领养宠物**不可删除**（仅可编辑），作为模块默认档案；
- 手动添加的宠物可自由删除。

## 五、异常与边界场景汇总

| 场景 | 处理规则 |
|---|---|
| 幼宠 <2 月龄 | 提示未离乳注意事项；疫苗计划从适龄（8 周龄）开始 |
| 老年宠 | 饮食/运动自动切换老年配方；体检每半年一次 + 专项检查 |
| 肥胖宠 | 饮食自动降热量 10-20%；运动循序渐进；提示避免剧烈运动 |
| 怀孕/哺乳期 | 提示咨询兽医调整饮食，不生成标准计划 |
| 多天未记录 | 不惩罚；首页温和提示「X 天未记录啦，今天的毛孩状态怎么样？」 |
| 多严重症状自查 | 直接红色预警，不展示家庭护理建议 |
| 疫苗补录历史日期 | 按实际日期计算下次接种时间 |
| 首启无宿主宠物 | 正常走「添加宠物」手动建档流程 |

## 六、数据流转说明

```
建档（功能1）→ 生成计划（功能2）→ 健康日历（2.6）
        ↓
日常记录（功能3：饮食/饮水/排泄/运动/体重/精神）
        ↓ 写入异常信号
预警引擎（功能5.1 自动规则 + 5.2 症状自查）
        ↓
提醒系统（功能6：推送 + 日历待办）
        ↓
统计与报告（功能7：评分/趋势/月度报告/导出）
```

- **记录 → 预警**：功能 3 各记录保存时即时检查预警规则（如食欲、布里斯托、饮水量、体重波动）；
- **预警 → 提醒**：预警生成后进入提醒队列，按优先级触发推送；
- **计划 ↔ 记录**：记录用于校验计划完成率（运动完成率、饮食达标率），并回写健康评分；
- **多宠物隔离**：以上全部流转按 petId 隔离。

## 九、验收要点（功能层面）

1. 首启自动带入宿主已领养宠物档案（类型/名字/头像正确）；
2. 🐱/🐶 建档后生成的疫苗/驱虫/热量计划互不相同且符合差异化规则；
3. 饮食记录勾选「拒食」→ 连续 2 天触发预警；
4. 🐱 排尿异常记录 → 红色高优先级预警；
5. 体重一周波动 >5% → 提醒；
6. 健康日历未来 30 天待办按日期正确排列；
7. 多宠物切换后数据完全独立；
8. 所有预警/自查结果底部有免责声明；
9. 入口卡片位于成长页，与 FitCut 卡片并列且主题一致。
