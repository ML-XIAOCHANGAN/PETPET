# PETPET 首版实现进度

> 记录日期：2026-08-09  
> 当前版本：`0.1.0`  
> 状态：本地原型已通过编译、静态检查和业务规则测试

## 一、本轮已完成

### 1.1 工程与架构

- 创建原生安卓单应用工程；
- 使用 `Kotlin` 与 `Jetpack Compose`；
- 配置 Java 17、Gradle 8.9、安卓 35 编译平台；
- 生成 Gradle 包装脚本；
- 配置国内依赖镜像优先、官方仓库后备；
- 针对中文项目路径启用安卓路径兼容开关。

### 1.2 领养与本地数据

- 首次进入显示领养页；
- 小猫名称限制为 1 至 12 个字符；
- 已有宠物时不会创建第二只；
- 宠物名称、领养日期、好感度和每日进度保存在本机；
- 社区动态、喜欢状态和评论保存在本机。

当前唯一领养由本地存储保证。接入服务端后，仍需使用数据库唯一约束和幂等接口形成最终保障。

### 1.3 聊天、互动与好感度

- 聊天输入限制为 200 个字符；
- 根据问候、情绪和提问等关键词提供本地安全回复；
- 每天第三轮有效聊天发放 `5` 点好感度；
- 聊天奖励每天最多一次；
- 每天前五次互动各发放 `1` 点；
- 超过互动上限仍有反馈，但不再增加好感度；
- 跨日后自动重置当天计数，好感度总值保留。

### 1.4 悬浮小猫

- 主动说明并申请系统悬浮权限；
- 授权后启动带常驻通知的前台服务；
- 通过系统应用上层窗口显示小猫；
- 支持拖动、左右贴边和位置保存；
- 点击悬浮小猫返回主应用；
- 支持应用内按钮和通知操作关闭悬浮小猫；
- 权限缺失时安全停止，不影响应用内功能；
- 服务使用非粘性重启策略，不强制反复拉起。

### 1.5 社区原型

- 内置两条演示动态；
- 支持发布纯文字动态；
- 支持喜欢和取消喜欢；
- 支持一级评论；
- 提供举报反馈入口；
- 提供用户与宠物信息页。

举报当前仅产生演示反馈，尚未接入审核队列。图片动态、拉黑、登录和真正的多人社区仍需服务端支持。

### 1.6 体素按钮

- 已安装用户指定仓库中的 `voxel-icon` 技能；
- 已完整读取技能主文件、风格规范、配色规范和两张内置校准图；
- 使用原生配色与静态输出模式；
- 创建可复用的代码原生体素按钮；
- 使用顶部、正面和侧面三个纯色面表达立体结构；
- 实现主要、陪伴、中性、危险和禁用状态；
- 实现按压下沉反馈；
- 替换领养、互动、聊天、悬浮窗、社区及底部导航按钮。
