# PETPET 体素按钮视觉规范

> 文档状态：已用于首版代码  
> 编写日期：2026-08-09  
> 视觉依据：`BIAsia/voxel-icon` 仓库中的 `voxel-icon` 技能

## 一、技能配置记录

```yaml
palette_mode: native
palette_preset: null
output_mode: still
```

用户没有指定奥利奥预设、定向配色或动画，因此必须使用原生配色与静态输出。PETPET 已有的珊瑚粉、暖黄、近黑和浅中性色关系保持不变，不引入无语义的额外色族。

## 二、按钮结构

按钮使用代码原生画布绘制，而不是圆角矩形或平面色块：

- 每个按钮是一个低密度长方体；
- 只显示顶部、正面和右侧面；
- 三个面采用同色系的整面明暗，不使用渐变；
- 顶面最亮，正面使用主色，右侧面最暗；
- 文字位于正面，由近黑或白色承担功能性对比；
- 不使用玻璃、透明、磨砂、金属、边缘发光、圆角和投影落地效果；
- 按下时按钮整体下移，顶部深度缩短，模拟真实方块按压。

## 三、颜色映射

### 3.1 主要按钮

- 顶面：`#FFB2A2`；
- 正面：`#F06F62`；
- 侧面：`#B54340`；
- 文字：`#2E2321`。

用于领养、发送、发布、开启悬浮小猫和当前选中的底部导航。

### 3.2 陪伴按钮

- 顶面：`#FFE096`；
- 正面：`#F4C44E`；
- 侧面：`#B88723`；
- 文字：`#33280E`。

用于摸摸小猫、已喜欢等温暖反馈操作。

### 3.3 中性按钮

- 顶面：`#FFFFFF`；
- 正面：`#EDEDEF`；
- 侧面：`#BFC0C5`；
- 文字：`#323231`。

用于评论、举报和未选中的底部导航。白色与近黑只承担结构和识别功能。

### 3.4 危险按钮

- 顶面：`#FF96A1`；
- 正面：`#E64D5C`；
- 侧面：`#A72C3C`；
- 文字：白色。

只用于关闭悬浮小猫等需要明确区分的操作。

### 3.5 禁用状态

禁用状态使用中性灰三面明暗，不降低透明度，避免背景透过按钮而破坏实体方块感。

## 四、背景与布局

- 应用浅色背景固定为 `#F4F4F4`，与技能要求的中性浅灰一致；
- 首版关闭自动深色主题，避免同一视觉体系在不同主题下发生背景漂移；
- 按钮保持至少 `42dp` 高，主要按钮为 `52dp`；
- 体素深度在紧凑按钮中为 `6dp`，主要按钮中为 `8dp`；
- 不添加地面、接触阴影或带方向的外部投影。

## 五、使用范围

首版下列交互已统一使用体素按钮：

- 确认领养；
- 摸摸小猫；
- 聊天发送；
- 开启、授权和关闭悬浮小猫；
- 社区发布、喜欢、评论、举报和评论发送；
- 小猫、社区、我的三个底部导航入口。

输入框、卡片和纯信息区不强行体素化，避免整个页面变成密集方块网格。体素语言集中在可操作控件上。

## 六、实现决定

`voxel-icon` 技能主要面向位图插画，但按钮属于需要适应不同屏幕密度、文字长度和按压状态的界面控件。图像生成技能也明确建议简单且可确定的界面图形优先采用代码原生方式。因此首版提取该技能的结构、投影、颜色与材质规则，通过安卓画布实时绘制，不生成固定尺寸按钮图片。

## 七、验收条件

1. 所有主要操作按钮可见顶部、正面和右侧面。
2. 同一按钮的三个面属于同一色族，且每个面内部为纯色。
3. 按钮没有圆角、透明度、渐变、边缘高光和接触阴影。
4. 按压时出现可感知但不突兀的下沉反馈。
5. 禁用按钮保持实体灰色，并且不可触发点击。
6. 文字在不同按钮状态下保持足够对比度。
7. 底部导航的选中项与未选中项可以通过体素配色明确区分。
