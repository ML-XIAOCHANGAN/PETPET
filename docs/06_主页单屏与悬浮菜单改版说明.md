# PETPET 首页单屏与悬浮菜单改版说明

> 更新日期：2026-08-09  
> 状态：代码实现完成，安卓构建与静态检查通过

## 一、本轮界面要求

1. `MY_PET` 的显示名称改为 `My Pet`。
2. 首页不再使用纵向长页面，不再显示聊天消息列表。
3. 聊天区域固定在底部导航栏上方，只显示一个输入框，提示文字为“今天过得还好吗”。
4. 点击小猫后，使用用户本轮提供的第一张气泡图片弹出随机问候。
5. 陪伴数据缩写后放在屏幕左侧，通过扩展栏查看聊天、互动和领养日期。
6. 用户本轮提供的第二张爪印图片放在 `My Pet` 标题右侧，作为悬浮小猫开关。
7. 点击系统悬浮小猫不再直接返回应用，而是展开互动、返回应用和聊天三个表情符号按钮。

## 二、首页固定布局

```text
┌────────────────────────────┐
│ My Pet       [日夜] [爪印] │
│ 宠物名字                   │
│          [图片气泡]        │
│ [陪伴›]    [小猫图片]      │
│                            │
│ [💬 今天过得还好吗] [发送] │
├────────────────────────────┤
│ My Pet    成长      社区   │
└────────────────────────────┘
```

首页根组件使用固定 `Column` 与中间自适应 `BoxWithConstraints`，没有 `LazyColumn` 或纵向滚动状态。中间宠物区域使用剩余高度，聊天框保持在该区域下方，因此不会形成长页面。

## 三、图片使用

### 3.1 对话气泡

- 原图归档：`docs/references/cat-assets/12_speech_bubble_source.png`
- 安卓资源：`app/src/main/res/drawable-nodpi/speech_bubble.png`
- 用途：点击小猫后作为问候文字的气泡底图
- 动画：缩放弹出并淡入，停留 2800 毫秒后缩小淡出

### 3.2 悬浮窗爪印按钮

- 原图归档：`docs/references/cat-assets/13_floating_paw_button_source.png`
- 安卓资源：`app/src/main/res/drawable-nodpi/floating_paw_button.png`
- 用途：标题右侧悬浮窗开关
- 行为：未开启时申请权限并启动，已开启时再次点击关闭并停用自启动

两张原图均未覆盖。安卓副本只进行顶部标记区域裁切、外围浅色背景透明化和 512×512 画布适配，没有程序重画气泡或爪印。

## 四、悬浮菜单行为

点击悬浮小猫时根据小猫所在位置向屏幕中间展开菜单：

| 按钮 | 行为 |
| --- | --- |
| `🐾` | 记录一次互动，并短暂切换为用户提供的眨眼图片 |
| `🏠` | 返回应用，保留当前应用状态 |
| `💬` | 返回 `My Pet` 页面，自动聚焦聊天输入框并弹出键盘 |

悬浮小猫仍可拖动和自动贴边。拖动结束时菜单自动收起，并保存小猫收起状态下的位置。

## 五、陪伴参数缩写

左侧收起状态只显示：

- `❤️`：当前好感度；
- `展开 ›`：扩展栏入口。

展开后增加：

- `💬`：当日聊天进度；
- `🐾`：当日互动进度；
- 领养日期。
